# 报销截图智能重命名工具

一款基于 OCR 和大模型的桌面 GUI 工具，自动识别电商订单截图中的实付金额和所属平台，按规则批量重命名文件。

## 功能特性

- **多平台识别**：支持淘宝/天猫、美团、拼多多订单截图
- **三模式识别**：云端视觉 API / 本地视觉模型 / OCR+文字模型
- **智能解析**：提取实付金额、平台名称、下单时间、商品名称
- **批量重命名**：自动按 `{金额}{平台}{原扩展名}` 格式重命名
- **结果预览**：识别后展示预览列表，支持手动修改
- **撤销支持**：重命名后可一键恢复原始文件名
- **日志记录**：生成详细处理日志，便于追溯
- **Excel 导出**：支持导出订单汇总和报销导入 Excel

## 技术栈

- **GUI 框架**：PyQt6
- **OCR 引擎**：RapidOCR（ONNX Runtime）
- **大模型**：支持本地 API（Ollama/LM Studio）和云端 API（OpenAI 兼容）
- **语言**：Python 3.x

## 快速开始

### 运行已编译版本

直接运行 `dist/XM报销OCR/XM报销OCR.exe`。

### 开发模式运行

```bash
cd app
pip install -r requirements.txt
python main.py
```

## 使用流程

1. 打开工具，点击「选择文件夹」选择包含订单截图的文件夹
2. 点击「开始识别」，工具逐张识别截图中的订单信息
3. 查看识别结果预览（原文件名 → 新文件名）
4. 点击「执行重命名」完成批量重命名
5. 如需撤销，点击「撤销」恢复原始文件名

## 识别模式

### 模式 A：云端视觉大模型 API
- 直接传图片给视觉大模型（GPT-4V / 通义 / 豆包等）
- 精度最高，需联网、有 API 成本

### 模式 B：本地视觉模型
- 本机部署视觉模型（Ollama / LM Studio）
- 离线可用，数据不出本机，需 GPU 或较大内存

### 模式 C：OCR + 文字模型（默认）
- RapidOCR 提取纯文本 + LLM 解析
- 成本低、兼容现有设备

## 支持的文件类型

- 图片：`.jpg`, `.jpeg`, `.png`
- 发票：`.pdf`

## 重命名规则

默认格式：`{price}{platform}{ext}`

示例：
- `QQ_1783556795637.png` → `26.52淘宝.png`
- `IMG_20260708_0046.jpg` → `14.6美团.jpg`
- `微信图片_202607090038.jpg` → `14.1拼多多.png`

## 配置说明

配置文件 `config.json` 包含：

- `settings`：输出模板、冲突策略、置信度阈值等
- `model`：模型选择、端点配置、API Key 等
- `last_folder`：上次使用的文件夹路径

## 平台判定规则

| 平台 | 特征词 | 说明 |
|------|--------|------|
| 淘宝 | `天猫` / `淘宝` / `企` | 淘宝/天猫订单截图必存字段 |
| 美团 | `闪购` | 美团订单截图特征词 |
| 拼多多 | `拼小圈` | 拼多多订单截图特征词 |
